PEDDLE PLUS AI PRICING CALCULATOR - WEB VERSION
=================================================

This package is built from the uploaded PeddlePlus-AI-Pricing_gdm project.
The original index.html, script.js, style.css and images are preserved.

FILES
-----
index.html
script.js
style.css
manifest.json
sw.js
images/logo.png.png
images/Qr Code.png

HOW TO TEST
-----------
Open index.html in a browser.

HOW TO PUT ONLINE FOR FREE (CLOUDFLARE PAGES)
---------------------------------------------
1. Open Cloudflare Pages.
2. Choose Create application / Pages.
3. Choose Direct Upload.
4. Upload the contents of this folder (or the ZIP).
5. Deploy.
6. Cloudflare gives you a public *.pages.dev link.

IMPORTANT
---------
- PDF generation uses the jsPDF/html2canvas libraries loaded from cdnjs, so the first online use should have internet access.
- Quotation/customer auto-save remains browser-local because the current calculator uses localStorage.
- This package does NOT add a server/database/login. It is a web-hosted version of the uploaded calculator.
